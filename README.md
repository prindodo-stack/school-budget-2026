# 학교별 예산 조회 웹페이지

## GitHub Pages 배포
1. GitHub에서 `school-budget-2026`라는 새로운 Public 저장소를 만듭니다.
2. 저장소의 Add file > Upload files에서 이 ZIP을 압축 해제한 `index.html`, `.nojekyll` 파일을 업로드합니다.
3. Settings > Pages > Build and deployment > Deploy from a branch를 선택합니다.
4. Branch: main / Folder: /(root) 선택 후 Save합니다.
5. 배포 후 https://prindodo-stack.github.io/school-budget-2026/ 로 접속합니다.

중요: 이 파일에는 모든 학교 예산이 포함되어 있습니다. 교번과 학교명 입력은 접근 통제나 인증 수단이 아닙니다. 공개 가능한 자료인지 반드시 확인하세요.
